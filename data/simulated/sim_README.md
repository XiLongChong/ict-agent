# 模拟数据集说明（佳华智审风险预警系统 · 演示用）

> **重要：本目录所有数据均为「模拟数据」，仅用于风险预警系统演示，绝不代表真实业务、真实企业与真实司法事件。**
> 生成时间：2026-08-13。所有文件每行均带 `数据来源=模拟数据` 标记。

## 为什么需要模拟数据

真实 7 表（销售/回款/应收/库存/合同/展期/授信）缺失风险预警需求所需的部分字段与对象：

| 缺失能力 | 真实数据现状 | 模拟补齐文件 |
|---|---|---|
| 担保人 | 无任何担保人字段 | `sim_guarantors.csv` |
| 项目阶段 / 计划回款日期 | 合同仅"流程结束/合同取消"，无里程碑 | `sim_project_stages.csv` |
| 事前评估新项目 | 无新项目流入（历史快照固定） | `sim_new_projects.csv` |

## 文件清单与字段说明

### 1. sim_project_stages.csv（30 行）

为真实项目合同补齐 项目阶段 / 计划回款 / 里程碑。关联键：`合同编号`（对应 `contracts.合同编号`、业务表 `合同号`）。

| 字段 | 说明 |
|---|---|
| 合同编号 | 真实合同编号（锚定 contracts 表） |
| 项目名称 | 真实项目名称 |
| 客户名称 | 真实客户名称 |
| 项目金额_万元 | 合同金额换算为万元 |
| 项目阶段 | 立项 / 执行 / 验收 / 回款 / 结束 |
| 计划回款日期 | 模拟计划收款时间 |
| 里程碑进度_% | 当前履约进度（0-100） |
| 计划交付日期 | 模拟计划交付时间 |

### 2. sim_guarantors.csv（30 行）

为真实客户与模拟新项目分配担保人。关联键：`客户编号`（对应 `customer_credit.客户编号_中台`）、`关联合同或项目`（真实合同编号 或 模拟项目编号 P2026-xxx）。

| 字段 | 说明 |
|---|---|
| 担保人ID | G001-G013 |
| 客户编号 / 客户名称 | 担保关系所属客户 |
| 担保人名称 | 模拟担保主体（企业或个人，与真实企业命名风格一致） |
| 担保类型 | 公司 / 个人 |
| 担保金额_万元 | 担保覆盖金额 |
| 担保人状态 | 正常 / 待核验 / 经营异常 / 失联待核验 |
| 关联合同或项目 | 项目P0xxx（存量）或 P2026-xxx（模拟新项目） |

> 特意包含 失联待核验（G004/G011）、经营异常（G001/G012）、待核验（G005）担保人，用于演示名单建议。

### 3. sim_new_projects.csv（20 行）

模拟新项目，用于**事前评估**与 **300/500/700 项目金额档位**演示。关联键：`项目编号`（P2026-101 ~ P2026-108）、`客户编号`。

| 字段 | 说明 |
|---|---|
| 项目编号 / 项目名称 | 模拟新项目标识 |
| 客户编号 / 客户名称 / 客户名单 | 所属客户及其名单（白名单/一般/黑名单） |
| 项目金额_万元 | **覆盖全档位**：180/300/450/500/620/700/760/920 |
| 金额档位 | <300 / 300~500 / 500~700 / ≥700（**300/500/700 = 项目金额万元，已确认**） |
| 授信金额_万元 | 模拟授信额度 |
| 担保人 | 模拟担保主体 |
| 申请日期 / 计划回款日期 | 评估与回款时间 |
| 备注 | 常规评估 / 边界档位 / 强制人工审批 / 黑名单拦截演示 等 |

> P2026-107 客户为黑名单（C058 深圳朔图），用于演示"事前评估黑名单拦截"；P2026-106 金额恰好 700 万，用于演示"≥700 强制人工审批"边界。

## 隔离与使用规则（必须遵守）

1. **绝不并入业务库**：模拟数据不参与 7 表导入（`import_data.py` 只接受 7 个正式文件名，不会读取本目录）。业务 DuckDB、案件库保持不变。
2. **独立读取**：风险预警新模块单独读取本目录（独立 demo DuckDB 或直接读 CSV），不混入真实指标。
3. **强制标注**：页面展示模拟对象时必须显示"模拟数据 / 演示数据"水印或徽标，不得让用户误以为真实抓取。
4. **影响边界**：模拟数据只影响演示页展示与演示健康度展示，**不进入真实健康度计算**；真实 7 表派生指标不受影响。
5. **可再生成**：修改 `generate_simulated_data.py` 后可重新生成，保持字段与关联键一致。

## 与真实数据的关联锚点

- 客户：`客户编号` C008/C015/C017/C020/C023/C031/C047/C058/C061 等（对应 `customer_credit.客户编号_中台`）。
- 合同：`合同编号` ZZSHF26030101 / HWSZF26010044WC 等（对应 `contracts.合同编号`）。
- 模拟新项目：独立 P2026-xxx 编号，仅存在于本目录。
