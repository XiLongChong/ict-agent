## 6. 问题与改进建议

优先级说明：P0 为系统不可用，P1 为核心流程阻断，P2 为重要但不阻断，P3 为一般体验改进。

### T3-01 [P2][无障碍][已修复] 搜索框清空按钮缺少可访问名称

- 位置：`frontend/src/components/ui/TextInput.vue`
- 现象：清空按钮功能正常，但按钮仅包含关闭图标，没有 `aria-label`，浏览器无障碍树中按钮名称为空。
- 影响：依赖屏幕阅读器的用户无法判断按钮用途。
- 建议：为按钮增加 `aria-label="清空搜索内容"`，并根据组件用途允许外部覆盖文案。

### T3-02 [P2][本地化][已修复] 名单建议中仍显示英文业务枚举

- 位置：`frontend/src/components/ListManagement.vue` 及名单建议返回文案。
- 现象：部分内容直接显示 `HEALTHY`、`WARNING`、`HIGH_RISK`、`HEALTH_GRADE_*` 等内部枚举。
- 影响：普通业务用户需要理解技术枚举，影响演示完整度和可读性。
- 建议：统一复用 `frontend/src/lib.js` 的中文映射；触发规则也应增加中文名称，不直接展示原始代码。

### T3-03 [P2][性能][已优化] 前端主 JavaScript 产物超过 500 kB

- 现象：主 JavaScript 文件约 762.01 kB，Vite 构建给出体积警告。
- 影响：在弱网或首次访问时可能增加下载、解析和执行时间。
- 建议：对业务路由使用动态导入，将 ApexCharts 等体积较大的依赖拆分为独立分包，并在优化后比较首屏指标。

### T3-04 [P3][状态提示][已修复] 成功提示跨页面持续显示

- 现象：完成一次事前评估后，顶部“事前评估完成”提示在舆情、名单、案件等其他页面仍持续显示。
- 影响：提示与当前页面上下文不一致，容易让用户误认为刚刚执行了当前页面操作。
- 建议：成功提示设置自动消失时间，或在路由切换时清除页面级提示。
