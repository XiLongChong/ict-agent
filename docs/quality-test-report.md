## 5. 本轮观察项（不阻断，需人工决策）

### O-1 [文档] AGENTS.md 测试数仍差 2 个
`AGENTS.md` 写“94 个 pytest”，实际 96（提交后新增 2 个舆情测试）。极小偏差，下次提交顺手更新即可。

### O-2 [产品] 存量合同视图被移除（项目评估只展示模拟新项目）
`list_projects_service` docstring：*“存量合同视图暂不下发（板块暂移除）”*；`/api/v1/projects` 现只返回 20 个 P2026-xxx 模拟项目。project.py 中真实合同风险指标计算（回款率/超期率/毛利/账期/风险等级）仍在且被测试覆盖，但**对外不可见**。若属临时策略，建议在 demo-script / user-guide 中说明；若长期，可评估移除死代码或明确标记为待启用。

### O-3 [口径] `risk_exposure` 口径已变更且无文档
`warning/overview.risk_exposure` 从「未 RESOLVED 预警金额（万元，仅模拟舆情 700）」改为「未关闭案件敞口合计（元，≈21.29 亿）」（`data.py:fetch_overview`）。前端已不展示该字段，但 API 仍在。**metric-contract.md 未记录该口径**，建议补充一句（金额单位“元”，来源 risk_cases.exposure_amount，排除 CLOSED）。

### O-4 [数据] 阶段 A 模拟数据扩充
舆情 12→45 条、模拟新项目 8→20 个、健康度主体 76→96（含项目合同）。sim_README 已同步。健康度分布由 11/50/14/1 变为 11/70/14/1（关注类增多，因新增项目合同主体评分偏低）。非缺陷，记录供核对。

### O-5 [Git] 工作区仍有未提交修改
`models.py / project.py / service.py / test_sentiment.py / generate_simulated_data.py / 5 个 sim CSV / HealthScores.vue / Projects.vue / RiskOverview.vue / lib.js / router.js / dist` 等 18+ 文件修改，及新增 `docs/user-guide.md`、`docs/quality-test-report.md`。建议尽快提交本轮修复，避免与后续改动混淆。

### O-6 [观察] 调查事件流仍见同一时刻多个 TOOL_STARTED
本轮两案事件流中仍出现 4/3 个 `TOOL_STARTED` 毫秒级连续发出（9.8s 三个、15.6s 四个）。若产品要求“严格禁止并行工具调用”（technical-solution §4.1），建议在 `agent.py` 显式设置 `max_parallel_tool_calls=1` 并补断言；若接受 Pydantic AI 的快速顺序调度，建议更新文档措辞。此为设计确认项，非功能缺陷。
