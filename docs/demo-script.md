# 五分钟演示脚本

1. 运行 `python backend/scripts/import_data.py`，展示 7 张表原子导入以及规则扫描摘要：38 个案件、
   47 条规则命中。
2. 运行 `uvicorn ict_agent.api:app --app-dir backend/src --reload`，打开风险总览。
3. 说明规则命中只表示“值得调查”，不会自动停供、调额或认定违约/滞销。
4. 展示案件构成：19 个客户应收案件、19 个库存案件，以及关键/高/一般优先级。
5. 打开 C015 应收案件，展示规则原因、观察期、风险金额和来源表。
6. 点击“开始 Agent 调查”，说明 Agent 按案件类型分步调用应收趋势、销售回款、当前订单、精确展期、
   授信和合同证据；金额与日期仍由 DuckDB 计算。
7. 展开调查报告，指出假设分为“证据支持、证据削弱、待补证”，并展示真实 `evidence_id` 对应的工具证据。
8. 强调 C015 的历史展期动作不能解释当前应收：只有客户、合同、订单、物料精确匹配才算当前展期证据。
9. 选择“暂时接受，持续观察”，填写审核人、原因和复查日期，展示原规则命中仍然保留。
10. 打开一个库存增长案件，说明 Agent 可以用销售增长和新库存占比判断“更符合正常补货”，但赛事数据
    没有促销活动和下游库存，不能声称“双十一备货”。
11. 打开经营分析和数据问答，说明原有确定性看板与通用问数作为辅助能力继续可用。
12. 打开 `/docs`，说明模型没有自由 SQL、文件、网络或业务写工具，案件库与可重建的业务事实库分离。
