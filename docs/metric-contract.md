# 指标与证据契约

本文件是分析工具的业务事实基线。代码、提示词和页面不得各自复制一份不同口径。

## 1. 通用规则

- 金额单位在工具内部统一为“元”；页面可格式化为万元/亿元，但必须标注单位。
- 比例的结构化值统一使用 `[0, 1]`，页面显示时转换为百分比。
- “最新一期”取对应快照表 `MAX(快照日期字段)`，并在答案中显示实际日期。
- 应收和库存快照是时点余额，只能按一个快照期聚合；跨期趋势应先按每个快照期分别聚合。
- 分母为 0 时比例返回 `null` 并附警告，不返回 0% 假装可计算。
- 退货沿用销售流水的负数量和负金额，不擅自取绝对值或删除。
- 所有结论必须标注来源表。探索 SQL 还需展示实际 SQL。

## 2. 核心指标

| 指标 | 计算口径 | 来源 |
|---|---|---|
| 销售额 | `SUM(销售金额_折扣后_含税)`，保留退货负值 | `sales` |
| 销售成本 | `SUM(出库成本金额)` | `sales` |
| 含税粗算毛利 | 销售额 - 销售成本 | `sales` |
| 含税粗算毛利率 | 含税粗算毛利 / 销售额 | `sales` |
| 回款额 | `SUM(回款金额)` | `payments` |
| 最新应收余额 | 最新月末截面的 `SUM(应收金额)` | `ar_snapshots` |
| 最新超期应收 | 最新月末截面的 `SUM(超期应收金额)` | `ar_snapshots` |
| 超期率 | 最新超期应收 / 最新应收余额 | `ar_snapshots` |
| 30 天以上超期率 | `SUM(超期30天以上金额)` / 最新应收余额 | `ar_snapshots` |
| 60 天以上超期率 | `SUM(超期60天以上金额)` / 最新应收余额 | `ar_snapshots` |
| 展期动作数 | `COUNT(DISTINCT gkey)`，不是展期表行数 | `extensions` |
| 最新库存金额 | 最新季末截面的 `SUM(含税总价)` | `inventory_snapshots` |
| 呆滞库存金额 | 最新季末、`库龄 > 180` 的 `SUM(含税总价)` | `inventory_snapshots` |
| 合同签约额 | `SUM(销售金额)` | `contracts` |
| 项目出库额 | 项目合同号匹配后的 `SUM(销售金额_折扣后_含税)` | `sales` |
| 项目回款额 | 项目合同号匹配后的 `SUM(回款金额)` | `payments` |

## 3. 关联规则

- 客户主键：`customer_credit.客户编号_中台` 对应其余业务表的 `客户编号`。
- 项目合同：`contracts.合同编号` 对应销售、回款、应收的 `合同号`。
- 销售/回款/应收/展期最细勾稽：客户编号 + 销售订单号；有合同号时同时带合同号。
- 非项目类合同号为空或未命中签约表是正常现象，不能作为数据错误。
- 库存无客户维度，只能通过物料编码和库存组织与销售进行有限关联；不得声称某库存必然属于某客户。

## 4. 结构化证据

每个工具统一返回以下语义：

- `summary`：供模型读取的短事实，不加入推测。
- `columns` / `rows`：用于页面表格或图表的数据，最多 200 行。
- `sources`：实际使用的 DuckDB 表名。
- `period`：查询覆盖的日期或快照日期。
- `metric_definitions`：本次涉及的口径短句。
- `warnings`：空列表或数据限制，例如分母为零、无客户维度。

Agent 最终答案必须区分“数据事实”和“建议”。建议可以由模型组织，但不得伪装成数据库已有字段。

## 5. 首期风险案件规则

启用规则集为 `2026.08-v1`，完整制定过程和回溯数量见
`docs/risk-rule-baseline.md`。规则命中只创建候选调查案件，不授权自动停供、调额、催收或结案。

| 规则 | 执行条件 | 优先级 | 风险金额 |
|---|---|---|---|
| `AR_DEEP_OVERDUE_MATERIAL` | 60 天以上超期 ≥ 100 万元，且最大超期 ≥ 90 天 | HIGH | 60 天以上超期金额 |
| `AR_EXPOSURE_BUILDUP` | 最新超期 ≥ 100 万元，较三个月前增加 ≥ 100 万元，且近三个月销售 > 回款 | HIGH | 最新超期金额 |
| `AR_BLACKLIST_EXPOSURE` | 当前黑名单状态为 2，且最新应收余额 > 0 | CRITICAL | 最新应收余额 |
| `INV_MATERIAL_BUILDUP` | 库存增加 ≥ 1,000 万元，且上季为 0 或增长比例 ≥ 50% | MEDIUM | 最新库存金额 |
| `INV_STALE_NO_SALES` | 180 天以上库存 ≥ 50 万元、占比 ≥ 30%，且近三个月销售 ≤ 0 | HIGH | 180 天以上库存金额 |
| `INV_BUILDUP_SALES_SLOWDOWN` | 库存增加 ≥ 300 万元、增长比例 ≥ 50%，且销售较前三个月下降超过 50% | HIGH | 最新库存金额 |

补充规则：

- 应收观察实体为客户 × 最新月末；库存观察实体为物料 × 库存组织 × 最新季末。
- `AR_EXPOSURE_BUILDUP` 中销售与回款差额只是方向性组合特征，不等同应收余额。
- 同一实体、观察期和规则集的多条命中合并为一个案件，优先级取最高值。
- 同一规则集、观察期和实体重复扫描必须幂等，不重复创建案件。
- 人工设置持续观察时必须填写复查日期，原规则命中继续保留。

## 6. 调查证据契约

调查 Agent 按案件类型使用固定工具，至少取得两项独立工具证据后才能生成报告。报告中的假设状态为：

- `SUPPORTED`：现有证据主要支持该候选原因。
- `WEAKENED`：现有证据主要反驳该候选原因。
- `UNRESOLVED`：关键证据缺失或证据相互矛盾。

每项工具证据生成唯一 `evidence_id`。报告只能引用本轮真实存在的编号；系统会删除模型产生的无效引用。
证据完整度由程序按真实工具数量计算，不接受模型自由生成百分比。

七表不支持的原因必须保持 `UNRESOLVED`：

- 银行到账但财务尚未核销；
- 项目未验收；
- 具体促销活动或下游客户库存变化；
- 工商司法等外部信用事件。

白名单、授信额度、信用保险或近期回款只能作为缓释证据，不能覆盖已发生的逾期事实。
