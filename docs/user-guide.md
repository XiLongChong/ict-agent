# 佳华智审 · 使用说明

> 面向使用者的界面功能说明。适用版本：2026-08（含阶段 A 风险预警系统）。
> 文档路由：架构见 `technical-solution.md`，指标口径见 `metric-contract.md`，规则见 `risk-rules.md`。

---

## 1. 系统简介

佳华智审是面向 ICT 渠道分销业务的风险调查与预警系统。系统把销售、回款、合同、应收、库存、展期、授信七张业务表导入本地数据库，通过确定性规则发现风险信号，再由 AI 在受控数据范围内完成证据调查，最后由人工复核决策。

核心链路：

```text
七张业务表 → 规则扫描 → 风险案件 → AI 调查 → 人工复核
        ↘ 健康度评分 → 名单建议 → 人工审批 → 名单治理
        ↘ 事前评估（模拟新项目）→ 评估结论
```

系统包含 **8 个界面**，按侧边栏顺序为：风险预警、案件队列、健康度、项目评估、舆情监控、名单管理、经营分析（另有案件处理工作台）。

> ⚠️ 演示数据提示：项目评估（模拟新项目）、舆情监控的数据为**模拟数据**，界面会标注"模拟"，不代表真实业务。

## 2. 启动系统

### 2.1 本地启动

```powershell
# 1. 安装依赖并配置 .env（见 README）
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env   # 填写 DEEPSEEK_API_KEY

# 2. 导入数据
python backend/scripts/import_data.py

# 3. 构建前端
cd frontend
npm ci
npm run build
cd ..

# 4. 启动服务
uvicorn ict_agent.api:app --app-dir backend/src --reload
```

访问 `http://127.0.0.1:8000/` 即可进入系统。

### 2.2 常用操作

| 操作 | 入口 |
|---|---|
| 重新扫描规则、刷新案件 | 顶栏"重新扫描"按钮 |
| 重算健康度并生成名单建议 | 健康度页"重算健康度"按钮 |
| 打开案件处理工作台 | 案件队列 / 风险预警 点击案件行 |

## 3. 界面功能说明

### 3.1 风险预警（`/risk`）—— 首页总览

系统默认首页，用于快速掌握整体风险态势。

**指标卡（6 个）**：

| 指标 | 含义 |
|---|---|
| 待事前评估 | 等待执行事前评估的模拟新项目数量 |
| 待处理案件 | 案件队列中未关闭的案件数（待调查 + 待复核 + 处理中） |
| 健康度下降 | 近 12 期健康度呈下降趋势的主体数 |
| 待审批名单 | 等待人工审批的名单调整建议数 |
| 未处理舆情 | 待核验 + 已确认的舆情数 |
| 健康度高危 | 健康度综合评分 <40 分（高危）的主体数 |

> 注：健康度"高危"与案件队列"高风险"是不同概念——健康度是六维指标综合评分，案件高风险是单条风险信号的调查优先级。

**主要区块**：
- **待办事项**：最新 5 条名单建议与预警（更多前往名单管理/舆情监控）
- **健康度分布**：健康/关注/预警/高危 四个等级的主体数量占比（环形图）
- **优先调查**：案件队列中优先级最高的 5 个案件（点击可打开案件工作台）

---

### 3.2 案件队列（`/cases`）—— 风险案件清单

展示规则引擎发现的全部风险案件。

**筛选**：案件类型（应收/库存）、处理状态（待调查/待复核/处理中/已关闭）、风险等级（高/一般/低）、关键词搜索。

**列表列**：案件主体、案件类型、风险概况（命中的规则）、风险等级、风险敞口、处理状态。

**分页**：每页 10/20/50 行，支持页码跳转。

**点击案件行**：打开案件处理工作台（新标签页）。

---

### 3.3 案件处理工作台（`/cases/{case_id}`）—— 单案件调查

单个案件的调查与复核中心，含三个页签：

1. **案件概况**：规则命中明细（规则、严重度、暴露金额）、风险敞口、规则版本、数据观察期。
2. **AI 审查**：
   - 点击"开始 AI 调查"后，AI 依次执行受控数据查询（实时流式展示工具调用过程）。
   - 报告区分四层：风险信号判断 / 工具证明的事实 / 证据支持的推测 / 无法判断的根因。
   - 每条事实和结论带证据编号，可展开查看查询参数与原始数据。
   - 刷新页面可回放调查轨迹。
3. **人工复核**：三种决策——确认风险（进入处理中）/ 需要补充证据（退回重新调查）/ 确认无风险（关闭案件），需填写复核人姓名与理由。

> 边界：AI 只做调查与建议，不自动停供、调额、催收或结案；所有处置由人工决策。

---

### 3.4 健康度（`/health`）—— 健康度评分列表

对客户（66 家）与项目合同（10 个）的综合健康评分。

**评分维度**：回款节奏（30%）+ 项目进度（20%）+ 应收超期（15%）+ 合同授信（15%）+ 担保人（10%）+ 舆情（10%），确定性计算、不消耗模型额度。等级划分：健康 ≥80 / 关注 60–79 / 预警 40–59 / 高危 <40。

**筛选**：主体类型（客户/项目合同）、等级（健康/关注/预警/高危）、关键词搜索。

**列表列**：主体、类型、分数（带进度条）、等级、近 12 期趋势（迷你折线）、主要拉低因素、计算时间。

**分页**：每页 10/20/50 行。

**"重算健康度"按钮**：重新计算全部健康度，并**自动生成名单调整建议**（供名单管理页审批）。

---

### 3.5 项目评估（`/projects`）—— 事前评估

对**模拟新项目**（P2026- 系列，8 个）执行立项前风险评估。

每个项目卡片展示：项目名称、客户、金额档位（<300 / 300~500 / 500~700 / ≥700 万元）、授信金额、担保人、计划回款日期。

点击"**事前评估**"后按确定性规则输出结论：
- **正常通过**：无黑名单、金额常规、历史回款正常
- **有条件通过 / 需要人工复核**：存在历史超期、高金额（≥500 万）等
- **暂缓项目 / 不建议通过**：担保人失联/经营异常、**黑名单客户**（如深圳朔图）、**≥700 万强制人工审批**

> 数据为模拟数据，仅用于演示评估流程；真实立项决策需结合真实业务系统。

---

### 3.6 舆情监控（`/sentiments`）—— 模拟舆情核验

模拟舆情事件列表（12 条），用于演示"外部信息 → 核验 → 风险联动"闭环。

**列表列**：标题/来源、发布时间、涉及主体（客户/担保人）、事件类型（失联/诉讼/失信/经营异常等）、严重程度（低/中/高/重大）、影响金额（万元）、真实性状态、关联项目。

**核验操作**（待核验的舆情可操作）：
- **确认属实**：写入预警记录（严重程度 ≥ 高时）与通知留痕，舆情纳入风险因子
- **排除（误报）**：标记为已排除，不再影响评分（如"同名误传"场景）

> 数据为模拟数据；已排除舆情不会影响健康度。

---

### 3.7 名单管理（`/lists`）—— 名单调整审批

白名单 / 观察中 / 黑名单三类名单的**变更决策中心**。

**建议来源**：健康度重算后自动生成（健康度预警/高危 → 建议进入观察中；健康度恢复健康 → 建议恢复白名单）。

每条建议展示：客户、当前名单 → 目标名单、触发规则、健康度变化、风险金额、复查日期（7 天后）。

**审批操作**（待审批状态）：
- **采纳**：记录名单变更审计（审批人、原因、时间），建议标记为已采纳
- **驳回**：保留驳回原因，不会自动重复生成同一条建议

> ⚠️ 重要边界：当前审批只做**决策留痕**（写审计记录），**不会实际修改客户授信主数据**——真实名单变更需在业务系统中执行。系统记录"谁、何时、基于什么证据、建议从哪个名单到哪个名单"。

---

### 3.8 经营分析（`/business`）—— 确定性经营看板

基于七张业务表的确定性指标看板（不消耗模型额度）：

- **核心指标**：销售金额（约 131 亿元）、回款金额（约 123 亿元）、最新应收余额、应收超期率
- **应收趋势**：近 6 个月 / 12 个月 / 全部 时间范围切换
- 用于业务全景概览与风险案件背景参考

## 4. 界面间的数据关系

```text
                ┌─────────────── 风险预警（总览）───────────────┐
                │ 指标卡 ← 各模块聚合                           │
                │ 待办事项 ← 名单建议 + 预警                     │
                │ 健康度分布 ← 健康度                           │
                │ 优先调查 ← 案件队列                           │
                └───────────────────────────────────────────┘

规则扫描 ──→ 案件队列 ──→ 案件工作台（AI 调查 → 人工复核）
健康度重算 ──→ 健康度列表 ──→ 名单建议 ──→ 名单管理（审批留痕）
模拟新项目 ──→ 项目评估（事前评估结论）
模拟舆情 ──→ 舆情监控（核验 → 预警 + 通知留痕）
七张业务表 ──→ 经营分析（确定性看板）
```

## 5. 常见问题

**Q1：健康度页没有数据？**
点击"重算健康度"生成。该操作会同时生成名单建议。

**Q2：名单管理审批后，名单为什么没变？**
系统当前只做决策留痕，不写客户授信主数据（安全边界设计）。见 3.7 说明。

**Q3：案件队列里没有看到某个客户？**
规则只对"命中阈值"的信号立案；黑名单客户未结应收属于已知存量风险，不进入主动发现队列（可在经营分析查看）。

**Q4：舆情监控的数据是真实的吗？**
不是，为模拟数据（界面有"模拟数据"标注），仅用于演示核验与联动流程。

**Q5：AI 调查会花多少钱？**
每次调查调用 DeepSeek 真实模型产生费用；健康度、经营分析、规则扫描均为确定性计算，不消耗模型额度。
