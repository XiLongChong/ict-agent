# 当前风险规则基线与回溯说明

## 1. 基线状态

- 规则集版本：`2026.08-v2`
- 单规则版本：`2.0.0`
- 数据观察期：应收截至 `2026-07-31`，库存截至 `2026-06-30`
- 数据规模：应收 24 个月末、库存 8 个季末、当前应收客户 35 家、最新库存物料组织组合 3,961 个
- 用途：发现仍在经营但风险正在显现的客户，以及库存与销售背离的早期信号
- 禁止用途：不得仅凭规则命中自动停供、调额、催收、计提，或认定违约、坏账和具体滞销原因

金额单位按赛事官方数据字典统一为人民币元。快照只取单一观察期，不跨期累加。

## 2. 筛选原则

规则引擎只控制调查入口，不负责最终定性。当前版本采用以下原则：

1. 黑名单客户的未结应收属于已知存量风险，不再进入主动发现队列；系统不重复证明企业已经知道的事实。
2. 应收重点筛选未进黑名单、近三个月仍有销售或回款活动，但逾期较深或敞口继续扩大的客户。
3. 库存重点筛选金额显著增加、高库龄且无销售、以及库存增加同时销售明显下降的物料组织组合。
4. 同一实体的多条规则合并成一个案件，优先级只表示调查顺序，不表示已经确认最终损失。
5. 规则集版本、实体和观察日期共同生成稳定案件编号；默认案件队列只展示最近一次规则集的结果。

## 3. 已启用应收规则

### AR_OPERATING_DEEP_OVERDUE：经营中客户大额深度超期

```text
黑白名单状态 != 2
AND 最近三个月存在销售或回款活动
AND 60天以上超期金额 >= 1,000,000
AND 最大超期天数 >= 90
```

- 优先级：`HIGH`
- 风险金额：60 天以上超期金额
- 数据来源：`customer_credit + ar_snapshots + sales + payments`
- 当前回溯命中：8 家客户
- 调查目标：判断老账是否持续、回款是否覆盖新增业务，以及风险是否在正常经营表象下继续恶化。

### AR_OPERATING_EXPOSURE_BUILDUP：经营中客户应收敞口加速积累

```text
黑白名单状态 != 2
AND 最新超期金额 >= 1,000,000
AND 最新超期金额 - 三个月前超期金额 >= 1,000,000
AND 最近三个月销售额 > 0
AND 最近三个月销售额 > 最近三个月回款额
```

- 优先级：`HIGH`
- 风险金额：最新超期金额
- 数据来源：`customer_credit + ar_snapshots + sales + payments`
- 当前回溯命中：2 家客户
- 调查目标：识别“业务仍在继续，但新增销售、回款和超期方向已经背离”的前瞻性敞口积累。
- 注意：销售与回款差额不等于应收余额，只是方向一致的组合证据。

两条应收规则合并后形成 10 个客户案件，共 10 条规则命中。

## 4. 已启用库存规则

### INV_MATERIAL_BUILDUP：库存金额显著增加

```text
本季库存 - 上季库存 >= 10,000,000
AND（上季库存 = 0 OR 库存增长额 / 上季库存 >= 50%）
```

- 优先级：`MEDIUM`
- 风险金额：最新库存金额
- 当前回溯命中：9 个物料组织组合
- 含义：只形成早期调查信号，不能直接写成滞销。

### INV_STALE_NO_SALES：高库龄库存且近期无销售

```text
180天以上库存金额 >= 500,000
AND 180天以上库存 / 最新库存 >= 30%
AND 最近三个月销售额 <= 0
```

- 优先级：`HIGH`
- 风险金额：180 天以上库存金额
- 当前回溯命中：9 个物料组织组合
- 含义：库龄结构和近期无销售共同支持呆滞风险，但具体原因仍需补证。

### INV_BUILDUP_SALES_SLOWDOWN：库存增加且销售显著下降

```text
本季库存 - 上季库存 >= 3,000,000
AND（上季库存 = 0 OR 库存增长额 / 上季库存 >= 50%）
AND 前三个月销售额 > 0
AND 最近三个月销售额 < 前三个月销售额 × 50%
```

- 优先级：`HIGH`
- 风险金额：最新库存金额
- 当前回溯命中：2 个物料组织组合
- 含义：库存和销售方向一致地恶化，形成滞销早期预警；七表不能证明促销、下游压货或客户应收因果。

三条库存规则合并后形成 19 个物料组织案件，共 20 条规则命中。

## 6. Agent 与人工审核边界

- Agent 必须把“风险信号是否成立”和“具体根因/最终损失是否确定”分开。
- 多项经营指标方向一致时，可以给出有证据引用的早期预警或恶化判断；不能因为根因未知而把整案写成
  证据不足。
- 没有核销、减值、司法或回收结果时，可以说“坏账风险上升”，不能说“已确认坏账”或“一定无法回收”。
- 规则只负责生成待 Agent 调查案件。人工复核决定风险成立、需要补充调查或确认无风险；规则不自动
  推进案件状态，也不触发具体业务处置。
- 原始规则命中、调查证据和人工审核历史保留，但默认队列只展示最新规则集案件。

## 7. 已知限制与复查重点

1. 库存没有客户维度，只能按物料与库存组织关联销售，不能把某项库存风险归因给特定客户。
2. 授信只有当前状态，没有历史名单变化时间，不能判断黑名单与逾期的先后因果。
3. 无销售使用销售金额 `<= 0`，包含退货净额为负的情况；后续可根据人工标签决定是否单独分型。
4. 风险召回率、误报率和损失预测需要人工审核标签或赛事方结局标签，不能仅靠七表计算。
5. 后续版本应优先依据审核结果调整阈值和组合条件，而不是增加更多无法解释的规则。
